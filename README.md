# 企业客户服务中台 · 演示站点

面向企业客户的健康保障中台演示环境，包含管理后台、数据大屏与在线理赔分析报告三部分，纯静态托管于 GitHub Pages。

## 页面

| 路径 | 说明 |
| --- | --- |
| `/` 或 `index.html` | 健康资金数据看板（大屏，深色，适配 1920×1080） |
| `manage.html` | 后台管理端：数据看板、支付信息、理赔信息、员工查询、理赔分析报告 |
| `report.html` | 在线理赔分析报告（结构化七章版式，支持导出 PDF） |

三个页面共用同一份数据集 `assets/data.js`，指标口径互通。

## 数据说明

`assets/data.js` 是**演示数据集**，全部为模拟数据：

- 被保险人 862 人，药房直付流水 1,720 笔，理赔案件 111 件（赔付 107 件、撤案 4 件）
- 案件明细包含险种、索赔性质、年龄段、医保类型、医院等级、诊断、补材原因、风控命中、多次出险等维度
- **报告中的所有统计数字均由明细实时聚合得出**，可逐项回溯到具体案件
- 保单期 2025-12-26 至 2026-12-25；统计期间 2026-04-01 至 2026-04-17，以结案日期为准
- 个人信息均做脱敏处理（手机号、证件号、姓名）

数据由脚本按固定随机种子生成，可完整复现。

## 导出

- 管理端各列表页：「导出 Excel」输出当前筛选结果的完整明细（真实 `.xlsx`，含多个工作表）
- 理赔分析报告页：「导出统计报表」输出 7 个工作表的统计报表
- 报告页：「导出 PDF / 打印」调用浏览器打印，按 A4 纵向排版；「下载原始 PDF」获取归档件

Excel 导出依赖 CDN 上的 SheetJS；网络不可用时自动降级为带 BOM 的 CSV，Excel 可直接打开。

## 本地预览

```bash
cd site
python3 -m http.server 8899
# 打开 http://127.0.0.1:8899/
```

需通过 HTTP 访问（`file://` 直开时浏览器会拦截部分资源）。

## 部署

推送到 `main` 分支后由 GitHub Pages 托管：

```bash
git add .
git commit -m "update"
git push
```

### 绑定自定义域名

若要使用 `cpic-dolphin.io` 之类的独立域名：

1. 在本目录新增 `CNAME` 文件，内容为裸域名（如 `cpic-dolphin.io`）
2. 在域名服务商添加解析：
   - `A` 记录 → `185.199.108.153`、`185.199.109.153`、`185.199.110.153`、`185.199.111.153`
   - `CNAME` 记录 `www` → `<用户名>.github.io`
3. 仓库 Settings → Pages 中填入自定义域名并开启 Enforce HTTPS
